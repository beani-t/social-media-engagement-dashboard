# Social Media Engagement Analytics Dashboard

An interactive marketing analytics dashboard designed and developed by Abeni Townsend.

## Overview

This project calculates social media engagement rate across major platforms and provides performance benchmarks and marketing recommendations.

## Features

- Platform selector for Instagram, TikTok, X/Twitter, Facebook, LinkedIn, and YouTube
- Engagement rate calculation
- Total engagement calculation
- Platform benchmark comparison
- Performance score
- Marketing recommendations
- Dark mode
- Copy results
- Download report
- Responsive design for desktop and mobile

- CSS
- JavaScript
